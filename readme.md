## what does this mod provide?

Starlit Valley: Odyssey - Core or SVO-Core for short is the backbone of the Starlit Valley: Odyssey modpack,
it's server as a integration and enhancement mod. Developed in java,
this core mod is designed to bridge the core mods of the modpack whilst also adding custom features.
