# What is Starlit Valley: Odyssey?
Starlit Valley: Odyssey is a modpack for Forge 1.20.1 that comes with a lot of custom content. 
The modpack's main goal is to provide a full Stardew Valley experience in Minecraft,
There are also some elements taken from Palia, Infinity Nikki, Animal Crossing and Genshin Impact.
There are also 2 endgame side quests:
- Norse Mythology
- Tech
